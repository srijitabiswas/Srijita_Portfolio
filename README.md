# Srijita Biswas – Portfolio Website

A modern and interactive portfolio website showcasing my work across Software Development, UI/UX Design, and Artificial Intelligence.

This portfolio highlights my projects, skills, and experiences through a user-centered design approach combined with modern frontend development practices. The website focuses on delivering a smooth, engaging, and visually appealing experience while demonstrating technical and creative capabilities.
